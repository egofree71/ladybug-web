# ladybug-web

Web version of the Lady Bug remake, built with Phaser 4, TypeScript and Vite.

This project is a web-oriented rewrite of the existing Godot 4 / C# remake.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the production version:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Tech stack

- Phaser 4
- TypeScript
- Vite

## Project status

This repository is being initialized. The first goal is to recreate the core Lady Bug gameplay for the web while using the existing Godot / C# implementation as a behavioral reference.
